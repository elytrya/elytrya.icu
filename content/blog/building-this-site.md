это сайт, который вы сейчас смотрите. коротко о том, как он создан.

## стек

- **nuxt 4** + **vue 3**
- **tailwindcss**
- **@nuxt/content** для блога
- **@nuxt/icon** для иконок
- **@nuxt/image** для изображений
- **bun** для запуска и зависимостей

## что внутри

- скрытый терминал по клавише `` ` ``
- command palette по Cmd/Ctrl + K
- счётчик времени разработки
- счётчик просмотров
- плавные анимации и переходы

## блог

новые записи добавляются обычными markdown файлами в `content/blog/`.
